# 中国跳棋（Chinese Checkers）设计规划

> 路线隶属 docs/PLATFORM.md。阶段一（同屏双人）= 2026-08-29 夜间子 Agent 并行开发；阶段二（AI）未排期。
> 实现模式遵循 src/games/gomoku/ 标杆。主要工作量在六角星棋盘的坐标与渲染。

## 一、规则规格

- **棋盘**：六角星 121 孔（中央六边形 13 列宽 + 六个三角臂）。引擎启动时预计算：孔坐标表 + 邻接表（每孔 2–6 个正邻），建议用 axial 坐标 (q, r) 生成后转直角百分比坐标供 UI 定位。
- **对局**：双人对角各 10 子（占据对角两臂），黑先（红先）轮流。v1 固定 10 子制。
- **走法**：二选一——
  1. 沿 6 个正邻方向走入相邻空孔；
  2. 跳过紧邻的一颗任意颜色棋子落到其正后方空孔，且**可连续跳**（链条中可变向）。
- **不吃子**。一次操作 = 走一步 或 一条完整跳链（引擎直接给出"从这个子出发一次操作可达的全部终点"）。
- **胜负**：己方 10 子全部进入对面出发臂（对方初始 camp）即胜。
- 无和棋机制（竞速游戏）；v1 不设循环着法判定。

## 二、阶段一交付（同屏双人）

- 引擎 `engine/chinese-checkers.ts`：棋盘几何生成（121 孔+邻接）、`movesFrom(state, from)`（含连跳闭包）、`place(state, from, to)`、`winner(state)`、undo（快照数组）。
- 交互：点击己方棋子 → 高亮该子一次操作可达的全部终点（含跳链终点）→ 点击终点完成操作；再点该子取消选中；不可动的子给出提示。
- UI：六角星布局用**绝对定位百分比坐标**渲染（容器 `min(92vw, 560px)` 正方形），孔为圆点，棋子为彩色圆片（两方用区分度高的双色，如靛蓝/玫红）。
- chips：手数、双方在营子数（进度感）；终局弹窗；悔棋。

## 三、测试清单（Vitest，全部须绿）

1. 几何：恰 121 孔；角臂孔邻居数正确（臂尖=2）；总邻接边数符合星形结构。
2. 相邻走一步生成正确。
3. 单跳、连跳（含变向）可达集合正确；跳链不可穿越两子或落在非空孔。
4. 胜利判定：10 子全部入对臂；差一子不算胜。
5. 非法目标拒绝；占用孔拒绝。
6. 悔棋快照一致性。

## 四、阶段二路线（AI 对手）

贪心推进（每步最小化距目标 sum）→ 前瞻 2-3 层 + 连跳长链优先；防"堵门"战术评估。Worker 化同既有模式。

## 五、已知取舍

- v1 双人固定对角、10 子制；不做 2/3/4/6 人多局与 6 子快棋（列入远期）。
- 连跳采用"一步直达终点"建模，不做逐孔动画演示（可后加）。
