# 国际跳棋（Checkers / Draughts，英式 8×8）设计规划

> 路线隶属 docs/PLATFORM.md。**本路线仅入库规划，未排期开发**（排在黑白棋/中国跳棋/中国象棋/国际象棋批次之后）。
> 实现模式遵循 src/games/gomoku/ 标杆。

## 一、规则规格（英式规则）

- **棋盘**：8×8，只用深色格；双方各 12 子摆在己方前三排深色格。
- **走法**：普通子沿斜前方向走一格；吃子沿斜向跳过相邻敌子落到其后空格。
- **强制吃子**：有吃必吃；**多跳强制走完**（连跳链必须跳到不能再跳）。
- **成王**：到达对方底线成王，王可沿斜向（含向后）走/跳。
- **胜负**：一方无子或无合法步判负。和棋：双方均只剩一王且短时间无进展（简化判定即可）。

## 二、阶段一交付（同屏双人）

- 引擎：吃子链生成（强制且必须走完）、成王、终局判定、undo（快照数组）。
- UI：8×8 只渲染深色格为可交互点；棋子圆形片，王加皇冠标记；连跳一步直达终点（同中国跳棋建模）；强制吃子时高亮必须吃的子。
- chips：子数、轮次、强制吃子提示；终局弹窗；悔棋。

## 三、测试清单（草案）

1. 普通走/吃生成；强制吃子过滤。
2. 多跳链必须走完；变向合法。
3. 成王后四向走/跳。
4. 终局：无子 / 无步判负。
5. 非法走子拒绝；悔棋一致性。

## 四、阶段二路线（AI 对手）

材料+王价值 → α-β（吃子延伸强制）；两端底线控制启发。Worker 化同既有模式。
