# 中国象棋（Xiangqi）设计规划

> 路线隶属 docs/PLATFORM.md。阶段一（同屏双人）= 2026-08-29 夜间子 Agent 并行开发；阶段二（AI）未排期。
> 实现模式遵循 src/games/gomoku/ 标杆。规则细节多，**测试清单是验收核心**。

## 一、规则规格

- **棋盘**：9 列 × 10 行交叉点（idx = r*9+c）。河界位于第 4/5 行之间；九宫：黑 r0–2 / c3–5，红 r7–9 / c3–5。
- **棋子与走法**（红先，红在下）：
  - 帅/将：九宫内每步一格直行；**飞将规则**：两将同列且中间无子 = 非法局面（等价于将可飞吃对将，走法生成必须排除）。
  - 仕/士：九宫内斜一格。
  - 相/象：田字（斜两格），**塞象眼**（田字中心有子不可走），不可过河。
  - 傌/马：日字，**蹩马腿**（先直后斜的那一格有子不可走该方向）。
  - 俥/车：直线任意距离，不可越子。
  - 炮/砲：直线平移同车；吃子必须隔恰好一个"炮架"。
  - 兵/卒：过河前每步只能前进；过河后可前进或左右横移，永不后退。
- **合法步** = 伪合法步 − 走完后己方被将军或构成飞将的局面。
- **将军 / 将死 / 困毙**：被将军须应将；轮到一方无任何合法步即负（中国象棋困毙=负，无逼和）。

## 二、阶段一交付（同屏双人）

- 引擎 `engine/xiangqi.ts`：棋盘表示、各子走法生成、将军检测、合法步过滤、`place`、终局判定（将死/困毙）、undo（快照数组）。
- UI：棋盘线条用 CSS 绘制（linear-gradient 网格 + 九宫斜线 + 楚河汉界文字），棋子为圆形片+汉字（红方朱红字/黑方墨字），摆放在**交叉点**上。
- 交互：点击己方棋子 → 高亮所有合法落点（含被吃子标记）→ 点击完成走子；将军时状态条显示"将军！"；终局弹窗（胜方 + 将死/困毙原因）；悔棋。
- chips：手数、轮次（红方/黑方）、将军提示。

## 三、测试清单（Vitest，全部须绿——这是验收核心）

1. 每类棋子基础走法各 ≥1 正例。
2. 蹩马腿、塞象眼、炮隔子打、兵过河前后差异，各 ≥1 正例 + 1 反例。
3. 飞将：同列无遮挡时走法被排除。
4. 被将军时只保留应将步；将死场景（如最小双车杀）判定终局。
5. 困毙场景判定终局（判负于无合法步一方）。
6. 非法走子拒绝；悔棋快照一致。

## 四、阶段二规格：AI 对手（本次实施）

- **分工**：人类执红先行，AI 执黑。
- **难度**：三档，工具栏内选择，默认中等：
  1. **简单**：深度 1（子料+位置分评估）——看不见对方回应，新手可胜。
  2. **中等**：α-β 深度 3 + MVV-LVA 走法排序 + 静态搜索（叶子延伸吃子，含隔一炮架的炮吃）。
  3. **困难**：迭代加深至深度 4–5（预算内）+ MVV-LVA + 杀手步/历史启发 + 静态搜索。分支因子约 40+，必须做候选剪枝与节点预算。
- **评估函数**：子料参考（车900–1000/马400/炮450/相仕各约200/兵过河前100、过河后200–300）；位置分：兵过河与深入敌方、中炮位、士象完整性等。具体数值实现自定，但"不白送车""白吃子必吃"等行为须有测试断言。保持确定性、无随机。
- **性能预算**：单步 ≤3s；节点数主预算（确定性可复现），墙钟兜底；迭代加深保证随时有最优步。
- **性能优化许可**：搜索路径允许 make/unmake 式走子/撤销、增量化将军检测等内部优化，**不得改变引擎既有公开 API 对外行为，既有 36 个测试保持全绿**。
- **不做**：置换表/Zobrist（后续选项）、长将/长捉与重复局面判定（既有取舍）、开局库。
- **Worker**：`xiangqi.ai.worker.ts` 薄封装（模式同 reversi/gomoku/chess）；UI 难度选择 + AI 回合锁盘 + "AI 思考中" chip + undoToHuman。
- **测试清单（新增，引擎层直接测 ai.ts）**：
  1. AI 输出必为合法步（多场景 × 三档）；
  2. 一步绝杀必找到（构造局面，三档全测）；
  3. 必胜残局（如双车挫）困难档在预算内找到获胜路径；
  4. 不白送大子：构造"送车"陷阱局面，中等/困难档不选送车着法；
  5. 白吃必吃：对方无保护的子与己方同价值子同格相换时，AI 敢换；
  6. 确定性：同一局面两次求解步与节点数完全一致；
  7. 预算合规：困难档最复杂中盘局面单步 ≤3s（墙钟）；
  8. 强度梯度：固定开局自对弈 hard vs medium 报告胜率（报告性，不作硬断言）。
