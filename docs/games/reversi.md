# 黑白棋（Reversi / Othello）设计规划

> 路线隶属 docs/PLATFORM.md。阶段一（同屏双人）= 2026-08-29 夜间子 Agent 并行开发；阶段二（AI）未排期。
> 实现模式遵循 src/games/gomoku/ 标杆：纯函数引擎 + Vitest 测试 + useReducer + Board/Game 组件。

## 一、规则规格

- **棋盘**：8×8。初始四子居中：白 (3,3)、(4,4)；黑 (3,4)、(4,3)（0 基行列）。**黑先行**。
- **合法落子**：必须使至少一条 8 方向直线上的连续对方棋子被己方新子与己方旧子"夹住"；落子后翻转所有被夹住的对方棋子（可多线同时翻转）。
- **跳过（pass）**：轮到一方无任何合法落子时，自动跳过并由对方继续，UI 必须明示"×方无合法落子，自动跳过"。
- **终局**：双方连续均无合法落子（或棋盘下满）。子多者胜，等数为和棋。

## 二、阶段一交付（同屏双人）

- 引擎 `engine/reversi.ts`：`initialState / legalMoves / place（含翻转与pass标记）/ undo`，全部纯函数。
- 交互：点击合法空位落子；合法落点显示半透明提示圆点；最后一手标记；双方子数 chips；轮次指示；悔棋。
- **悔棋实现建议**：用状态快照数组（每步 push 完整状态），pass 逻辑天然可回退，避免事件逆演。
- 终局弹窗：胜方/和棋 + 比分 + 再来一局。
- 移动端：棋盘 `min(92vw, 520px)` 自适应。

## 三、测试清单（Vitest，全部须绿）

1. 初始局面恰好 4 子、黑先、合法步为 4 个。
2. 八方向翻转正确性；一条落子同时翻转多条线的场景。
3. 边界/角落落子（角是强点，不得越界翻转）。
4. 无合法步 → 自动 pass，轮次不变方连续行动。
5. 双方均无合法步 → 终局判定与胜负。
6. 悔棋（含跨越 pass 的悔棋）恢复到正确快照。
7. 拒绝非法落子（不夹子/占用已有子）。

## 四、阶段二路线（AI 对手）

贪心（翻最多）→ 位置权重表（角无穷大、C 位/星位负分）→ 极小极大 + α-β（深度 4-6，行动力评估）。Worker 化同独立钻石求解器模式。
